# Flask Portfolio Website

A responsive portfolio website built with **Python** and **Flask** to showcase my web development projects, technical skills, and practical experience in front-end and back-end development.

## Features

* Responsive and mobile-friendly interface
* Dynamic page rendering with Flask
* Project showcase section
* Clean and simple UI design
* Organized structure for easy maintenance

## Technologies

* Python
* Flask
* HTML5
* CSS3
* JavaScript

## Project Goal

This project was developed to strengthen my Flask and web development skills while creating a professional platform to present my projects and experience.
